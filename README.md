# Portfolio Site

A personal portfolio showcasing my backend engineering work, built with React, Spring Boot and PostgreSQL and deployed on AWS.

## Run the frontend

Requires Node.js 22.16.0 (see `frontend/.nvmrc`).

```sh
cd frontend
npm install
npm run dev      # http://localhost:5173
```

Other scripts: `npm test`, `npm run lint`, `npm run format`, `npm run build`, `npm run preview`.

See [SPEC.md](SPEC.md) for scope and architecture.
